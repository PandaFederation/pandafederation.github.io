MCP

Servers for agents that need public data.

Install from PyPI with one uvx command (Python 3.11+ and uv). The four focused domain servers run our Apify Actors, so they need your own APIFY_TOKEN; runs bill to your Apify account at the prices on each Store page. Quiet File Team MCP is free, offline and needs no token.

Pick one focused server rather than the umbrella: fewer tools means your agent picks the right one more often. The focused servers and Quiet File Team MCP are on the Official MCP Registry; all six are on Glama.

Panda Research Tools

MCP server: 8 research-integrity tools — fake/retracted citation checks, OpenAlex, PubMed, experts.

Install

uvx panda-research-tools
MCP client config
{"mcpServers":{"panda-research-tools":{"command":"uvx","args":["panda-research-tools"],"env":{"APIFY_TOKEN":"YOUR_APIFY_TOKEN"}}}}

Ask your agent

  • “Check these 12 references for fake, miscited or retracted papers and tell me which to replace.”
  • “Find recent PubMed studies on intermittent fasting and build an evidence table I can open in Excel.”
