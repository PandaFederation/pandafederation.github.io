# Quiet File Team MCP · Panda Federation

Source: https://pandafederation.com/quiet-file-team-mcp/

Quiet File Team MCP gives Claude, Cursor or any MCP client six offline tools that explain, configure and check a Quiet File Team — several bots sharing one computer through files. Nothing leaves your machine: no network calls, no file reads of your disk, no paid APIs.

Use it with the free [Bash core](../quiet-file-team/) (scripts on [GitHub](https://github.com/pandadad0214/quiet-file-team)), or with the optional paid [Quiet File Team Setup Kit](https://agensi.io/skills/quiet-file-team-setup-kit) on Agensi when you want a guided install.

## Install

Python 3.11+ and [uv](https://docs.astral.sh/uv/) on the client. No account or token is required.

```
uvx quiet-file-team-mcp
```

Published on [PyPI](https://pypi.org/project/quiet-file-team-mcp/) and listed on the [Official MCP Registry](https://registry.modelcontextprotocol.io/v0/servers?search=io.github.pandadad0214/quiet-file-team-mcp) as `io.github.pandadad0214/quiet-file-team-mcp`.

MCP client config:

```
{"mcpServers":{"quiet-file-team":{"command":"uvx","args":["quiet-file-team-mcp"]}}}
```

## Tools
**explain_method**Concepts and trust limits before an exercise.**generate_team_config**Safe roster and zone defaults; lead-only coordinator.**generate_early_exit**Draft a quoted early-exit block for a supplied role/path.**validate_layout_manifest**Compare supplied relative paths (no real filesystem scan).**draft_workflow**Fictional practice steps for the default roster.**draft_owner_batch**Deduplicate owner questions; keep unresolved task refs.
