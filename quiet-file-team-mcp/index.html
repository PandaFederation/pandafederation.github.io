Quiet File Team MCP

Six free offline MCP tools for file-first agent teams

FreeMITNo network callsstdio / uvx

Quiet File Team MCP gives Claude, Cursor or any MCP client six offline tools that explain, configure and check a Quiet File Team — several bots sharing one computer through files. Nothing leaves your machine: no network calls, no file reads of your disk, no paid APIs.

Use it with the free Bash core, or with the optional paid Quiet File Team Setup Kit on Agensi when you want a guided install.

Install

Python 3.11+ and uv on the client. No account or token is required.

uvx --from git+https://github.com/pandadad0214/quiet-file-team-mcp.git@v0.1.0 quiet-file-team-mcp

MCP client config:

{"mcpServers":{"quiet-file-team":{"command":"uvx","args":["--from","git+https://github.com/pandadad0214/quiet-file-team-mcp.git@v0.1.0","quiet-file-team-mcp"]}}}

Tools

explain_methodConcepts and trust limits before an exercise.
generate_team_configSafe roster and zone defaults; lead-only coordinator.
generate_early_exitDraft a quoted early-exit block for a supplied role/path.
validate_layout_manifestCompare supplied relative paths (no real filesystem scan).
draft_workflowFictional practice steps for the default roster.
draft_owner_batchDeduplicate owner questions; keep unresolved task refs.

Switch editions

  • Free MCP companion — this page. Install with the uvx command above. Source is on GitHub.
  • Free Bash core — clone quiet-file-team, set TEAM_DIR to the checkout, and follow its README. This MCP explains and checks a team; it does not install those scripts.
  • Quiet File Team Setup Kit — paid Agensi skill, $29 one-time on the live listing. Guided local install, ready rules, and practice files. Open Agensi
  • Setup kit generator — paid Apify Actor that builds a configured starter ZIP. Live price is on the Store page. Open Apify Store
